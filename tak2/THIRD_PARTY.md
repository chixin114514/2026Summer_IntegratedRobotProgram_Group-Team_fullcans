# Third-Party Resources

## Elephant Robotics mycobot_ros2

The robot description used in Task 2 is derived from the official
Elephant Robotics ROS 2 repository.

Repository:
https://github.com/elephantrobotics/mycobot_ros2

Branch:
humble

Imported package:
mycobot_description

Target robot:
mechArm 270

The original license file is preserved inside the imported
mycobot_description package.

The Task 2 project-specific simulation, control, launch, configuration,
pick-and-place logic, safety handling, and experiment logging are
implemented separately in this repository.
