# Lab 0 Computer Vision Experiments

This directory contains the two computer-vision experiments and their reproducible artifacts.

| Directory | Experiment | Main deliverables |
| --- | --- | --- |
| `lab0-1/` | Experiment 2: smartphone-camera intrinsic calibration | English report, OpenCV calibration program, checkerboard dataset, calibration matrices, and accuracy results |
| `lab0-2/` | Experiment 3: stereo depth estimation | English report, StereoSGBM program, OpenCV aloe stereo data, disparity/depth maps, and PLY point cloud |

Both experiments include a README, source code, report, and generated results. The numerical depth in `lab0-2` uses an explicit demonstration baseline and focal length because the OpenCV sample pair has no physical stereo calibration.
