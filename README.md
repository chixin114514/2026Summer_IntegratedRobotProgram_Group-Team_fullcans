# 2026 Summer Integrated Robot Program - Group Project

## 项目简介

本仓库用于保存夏季学期“机器人集成小组项目”的代码、配置文件、实验记录以及相关文档。

项目采用 ROS 2 作为机器人软件开发与通信框架，各实验任务按照独立目录进行组织，便于小组成员协作开发、版本管理以及实验验收。

## 项目结构

当前项目按照不同实验任务分别组织。

其中：

- `tak2/`：机械臂定点抓取实验

## 开发原则

- 使用 Git 和 GitHub 进行小组协作与版本管理
- 每完成一个独立代码阶段进行一次 commit
- Mac 主要用于代码编写和 Git 管理
- Jetson Ubuntu 主要用于 ROS 2、Gazebo 仿真和真机验证
- 完成仿真验证后再进行真实机械臂实验
